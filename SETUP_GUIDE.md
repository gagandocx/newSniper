# CoderSnap — Quick Setup Guide

## Step 1: Install the Extension

1. Extract the **CoderSnap.zip** file to a folder on your computer
   - Example: `C:\CoderSnap\`
   - **Don't delete this folder** — Chrome needs it

2. Open Chrome and go to: `chrome://extensions`

3. Turn ON **Developer Mode** (top-right toggle)

4. Click **"Load unpacked"**

5. Select the `CoderSnap` folder you extracted

6. Done! You'll see the CoderSnap icon in your toolbar

---

## Step 2: Activate Your License

1. Click the **CoderSnap icon** in your Chrome toolbar

2. Enter your **License Key** (format: XXXXX-XXXXX-XXXXX-XXXXX)

3. Enter your **Amazon hiring account email**

4. Click **"Activate License"**

5. You'll see "LICENSED" with days remaining — you're activated!

---

## Step 3: Set Up AI CAPTCHA Solver (Free — Highly Recommended)

This lets CoderSnap auto-solve CAPTCHAs so login never stops.

1. Go to: https://console.groq.com/keys
2. Sign up for free (no credit card needed)
3. Click **"Create API Key"** — name it anything
4. **Copy the key** (starts with `gsk_`) — Groq only shows it ONCE!
5. Click CoderSnap icon → find **"GROQ API KEY"** field → paste your key
6. Green checkmark = saved!

---

## Step 4: Configure Your Search

Click the CoderSnap icon and set:

| Setting | Recommended |
|---------|-------------|
| **Region** | City closest to where you want to work |
| **Radius** | 50–150 km |
| **Shift Type** | Any |
| **Target Cities** | Click "Any City" for maximum results |
| **Scan Interval** | 2 seconds |

---

## Step 5: Start Hunting

1. Go to https://hiring.amazon.ca (or .com)
2. Sign in to your Amazon hiring account
3. **Allow pop-ups** when prompted (one-time):
   - Click the lock icon in address bar → Site settings → Pop-ups → Allow
4. Click CoderSnap icon → toggle **"ACTIVATE HUNTER"** ON
5. That's it! CoderSnap scans every 2 seconds and auto-applies when a job appears

---

## Important Notes

- **Keep the Amazon tab open** — scanning only works while the tab is active
- **Keep Chrome running** — scanning stops if you close the browser
- **One license = one Amazon email = one computer** — cannot be transferred
- **License is valid for 1 year** from activation date
- If CAPTCHA appears during login, CoderSnap solves it automatically (requires Groq key)
- You'll hear a sound + get a notification when a job is found and applied to

---

## Troubleshooting

| Problem | Fix |
|---------|-----|
| Extension not scanning | Make sure Hunter toggle is ON + you're on hiring.amazon.ca |
| "Rate limited" | Normal — auto-retries in a few seconds |
| CAPTCHA blocks login | Set up Groq API key (Step 3 above) |
| No jobs found | Increase radius to 150km + use "Any City" |
| License says expired | Your 1-year license ended — contact admin for renewal |
